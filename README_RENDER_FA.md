# ADVERSING — نسخه آماده‌سازی‌شده برای Render

## پیش‌نیازها
- مخزن GitHub (پیشنهاد: Private)
- یک دیتابیس MySQL قابل‌دسترسی از اینترنت. Render سرویس رایگان MySQL داخلی ارائه نمی‌کند؛ دیتابیس باید از سرویس جداگانه تهیه شود.

## ۱) آپلود به GitHub
1. ZIP را از حالت فشرده خارج کنید.
2. همه فایل‌های داخل پوشه `adversing_render` را در یک مخزن GitHub قرار دهید (خود ZIP را آپلود نکنید).
3. مطمئن شوید فایل `Dockerfile` در ریشه مخزن باشد.

## ۲) ساخت سرویس Render
1. وارد https://render.com/ شوید و از داشبورد New + → Web Service را انتخاب کنید.
2. مخزن GitHub را وصل کنید.
3. در تنظیمات سرویس، Runtime/Environment را Docker انتخاب کنید و Deploy را بزنید.
4. Render مقدار `PORT` را تعیین می‌کند؛ Dockerfile و entrypoint این مقدار را تنظیم می‌کنند.

## ۳) متغیرهای محیطی
در Settings → Environment، این متغیرها را اضافه کنید (مقادیر واقعی را از ارائه‌دهنده MySQL بگیرید):
- `DB_HOST` = نام میزبان دیتابیس، بدون پورت
- `DB_PORT` = پورت دیتابیس، معمولاً `3306`
- `DB_NAME` = نام دیتابیس
- `DB_USER` = نام کاربر دیتابیس
- `DB_PASSWORD` = رمز دیتابیس
- `APP_URL` = آدرس HTTPS سایت پس از ساخته‌شدن، مانند `https://your-service.onrender.com`
- `ALLOW_INSTALL` = `1` فقط هنگام نصب اولیه
- `PAYMENT_PROVIDER` = `manual` تا زمانی که درگاه واقعی تنظیم نشده

این متغیرها را فقط در داشبورد Render وارد کنید، نه در کد عمومی GitHub.

## ۴) نصب دیتابیس و مدیر
1. پس از Deploy موفق و تنظیم متغیرهای دیتابیس، در مرورگر آدرس `https://آدرس-سایت/install.php` را باز کنید.
2. یک نام کاربری مدیر و رمز قوی حداقل ۱۲ نویسه بسازید.
3. پس از پیام موفقیت، حتماً `ALLOW_INSTALL` را از Environment حذف کنید یا روی `0` بگذارید و دوباره Deploy کنید.
4. سپس وارد `https://آدرس-سایت/admin/login.php` شوید.

## نکته‌های مهم
- فایل‌های آپلودشده در فضای محلی سرویس رایگان Render ماندگار نیستند. برای سفارش‌های واقعی و طرح‌های ارسالی مشتری، فضای ذخیره‌سازی دائمی/سرویس فایل جداگانه لازم است.
- این ZIP برای تنظیمات اجرای Render آماده شده است؛ قبل از فروش واقعی، ثبت‌نام، ورود، سبد خرید، ثبت سفارش، پنل مدیریت و بارگذاری فایل‌ها را آزمایش کنید.
- درگاه پرداخت روی حالت دستی قرار دارد و تراکنش واقعی انجام نمی‌دهد تا زمانی که تنظیمات معتبر درگاه اضافه شوند.
- هیچ رمز دیتابیس یا کلید پرداختی را در چت یا مخزن عمومی قرار ندهید.
